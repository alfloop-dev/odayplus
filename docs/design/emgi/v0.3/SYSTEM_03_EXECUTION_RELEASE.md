# EMGI Parallel Execution and Release

Binding execution details are defined by `EXECUTION_01_RULES_AND_INVENTORY.md`, `EXECUTION_02_SOURCE_MODEL_VERIFICATION.md`, `tasks/manifest.json`, and the G0–G7 integration gates in the package index. API and UI start from contract fixtures; central registries and ordered migrations are generated-only; release requires durable readback, evidence, independent review, canary, restore, rollback and kill-switch proof.
