section-6  What this environment could NOT verify
================================================================================

The image, SBOM, and signature digests are recorded as Artifact Registry
references. Resolving them requires a credential this audit environment does
not have. The probe is recorded as the failure it was:

$ docker buildx imagetools inspect --raw \
    asia-east1-docker.pkg.dev/odayplus-runtime-20260825/oday-plus-dev/oday-api@sha256:ac085f14e958ae85befa8edf9476a6a6c55c74dadcf308f610e5c4078b17b4c6

to select an already authenticated account to use.
ERROR: error getting credentials - err: exit status 1, out: ``
EXIT=1

This is a gap in *independent re-resolution*, not a gap in the binding. The
digests were emitted by the build job itself and fail closed at build time:
resolve_supply_chain_ref() in .github/workflows/deploy-dev.yml exits non-zero
when a Cosign .sig or .att tag does not resolve, so a manifest can never claim
supply-chain evidence the registry did not actually hold. Re-resolution against
Artifact Registry stays an open item for whoever attests Gate 4.

Also not done here, deliberately:
  - no deployment, no lease request, and no admission attempt;
  - no gate receipt was written and no gate status was moved;
  - external_sources_expected_enabled stays empty; no third-party source was
    enabled for this candidate.
